Практическое занятие №3: Разработка клиент-серверного веб-приложения (Модуль онлайн-кинотеатра) 
Описание проектаПриложение «Модуль анализа предпочтений и истории просмотров онлайн-кинотеатра» представляет собой 
полнофункциональный клиент-серверный веб-интерфейс, позволяющий пользователям вести учет просмотренных фильмов, 
выставлять оценки, фиксировать процент досмотра и управлять историей просмотров.Проект разработан в рамках дисциплины 
«Разработка клиент-серверных приложений» (РКСП). Технологический стекFrontend: HTML5 (семантическая верстка), 
CSS3 (Flexbox, анимации состояний), JavaScript (ES6+, Async/Await, Fetch API, DOM API).Backend: Node.js, Express.js, 
CORS middleware.Инструменты: VS Code, Live Server, npm.📂 Структура проектаcinema-app/
│
├── client/                  # Клиентская часть (Frontend)
│   ├── index.html           # HTML5-структура страницы (форма и таблица)
│   ├── style.css            # Стилистика оформления и индикаторов состояний
│   └── app.js               # Клиентская логика, DOM-манипуляции, Fetch-запросы
│
└── server/                  # Серверная часть (Backend)
    ├── server.js            # Express-сервер и REST API эндпоинты
    ├── package.json         # Зависимости проекта (express, cors)
    └── README.md            # Документация проекта
Инструкция по запуску1. Запуск серверной части (Backend)Перейдите в директорию сервера:cd server
Установите необходимые зависимости (если не были установлены ранее):npm install
Запустите Express-сервер:node server.js
Сервер запустится на порту 3000 и вывод покажет: Сервер успешно запущен на порту 3000.2. Запуск клиентской части (Frontend)Откройте файл client/index.html в VS Code.Запустите страницу через расширение Live Server (правая кнопка мыши -> Open with Live Server).Приложение откроется по адресу http://127.0.0.1:5500/client/index.html.🔗 REST API ЭндпоинтыМетодЭндпоинтОписаниеGET/api/v1/moviesПолучить всю историю просмотров и оценокPOST/api/v1/moviesДобавить новый фильм/сеанс (принимает JSON)DELETE/api/v1/movies/:idУдалить запись просмотров по её ID
